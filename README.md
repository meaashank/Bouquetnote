**BouquetNote** is an exquisite, interactive digital floral studio and virtual bouquet maker. Designed with refined editorial aesthetics, it allows users to arrange bespoke botanical compositions stem-by-stem, customize artisan wrapping papers and silk ribbons, fine-tune layering and scale via a data-driven composition engine, and generate personalized AI verses for loved ones.

## ✨ Core Features

* **Interactive Stem Composition Engine**: Drag, drop, scale, rotate, and layer botanical stems with high precision and component-level hitboxes.
* **Artisan Wrapping & Ribbon Gallery**: Select from fine kraft paper, silk white, sage linen, and noir velvet wrapping papers paired with bespoke silk ribbon ties.
* **AI-Powered Verse & Note Generator**: Automatically compose heartfelt poetic notes tailored to your recipient using integrated Gemini AI logic.
* **Sanctuary Digital Garden**: Save, view, and preserve your floral creations across sessions with high-fidelity editorial presentation cards.
* **Mobile-First Responsive Design**: Optimized viewport layout with collapsible mobile stem pickers and streamlined bottom control bars.

## 🛠️ Getting Started Locally

Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/bouquetnote.git
cd bouquetnote
npm install
```

Run the development server on port `3000`:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
